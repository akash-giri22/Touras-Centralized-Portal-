# Touras Enterprise Portal

## HOW TO RUN

### OPTION 1 - Node.js (Recommended)

1. Install Node.js from https://nodejs.org (LTS button)
2. Restart your computer
3. Extract ZIP to C:\Projects\touras
4. Double-click start.bat (or right-click > Run as Administrator)
5. Open http://localhost:3000

### OPTION 2 - Docker

1. Install Docker Desktop from https://www.docker.com/products/docker-desktop
2. Open Docker Desktop, wait for "Docker is running"
3. Double-click docker-run.bat
4. Open http://localhost:3000
